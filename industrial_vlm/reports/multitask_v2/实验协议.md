# 第二轮：在固定图片曝光预算下比较任务分配

第一轮发现，同一个区域 SFT 适配器改用判断提示后，会漏掉一些原来检出的异常。本轮检验：在固定图片曝光预算下，混合判断与区域任务能否改善判断能力和提示一致性，以及需要付出多少定位代价。结果可以否定这个假设。

## 已冻结的控制条件

| 训练臂 | 每张源图的两次训练 | 独立源图 | 图片曝光 | 更新次数 |
|---|---|---:|---:|---:|
| RR：region_region | 区域、区域 | 768 | 1,536 | 192 |
| DD：decision_decision | 判断、判断 | 768 | 1,536 | 192 |
| RD：region_decision | 区域、判断，顺序按来源分层打散 | 768 | 1,536 | 192 |

三个训练臂从相同 Qwen3-VL-8B-Instruct 量化基座重新初始化 LoRA。使用相同 seed、实际图片序列、输入像素上限、梯度累计、优化器、学习率调度和 LoRA 配置。每个类别与标签的来源数相同；RD 每个 epoch 内的两种任务数量也相同。

语言 Linear 使用 NF4，视觉编码器与连接模块冻结 BF16；语言注意力 q/k/v/o 使用 r=16、alpha=32 的 LoRA。每次更新累计 8 张完整图片，max_pixels=524,288，max_length=2,048，lr=1e-4，warmup=10。固定第 192 次更新后的适配器作为结果；中间验证 CE 只作诊断。

训练逐次记录成功更新使用的 source_id、样本 id、任务、输入 token 和监督 token，核验三臂实际图片曝光顺序完全相同。同时保存初始 LoRA 参数 SHA256，以核验初始化一致。

区域答案较长，三臂的监督 token 数与输入 token 数不同。梯度仍按一次累计更新中的监督 token 总数归一化，因此 RD 的任务样本各占一半，不等于两个任务的损失权重各占一半。本轮比较的是有限曝光预算下的任务分配效果。

## 验证与确认集的用途

本轮在既有的 120 张验证图上做五项生成评估：三个适配器都使用相同判断提示，RR 和 RD 另使用相同区域提示。报告二类 macro F1、异常召回、正常误报率、框召回，以及同图在两个提示下的判断一致性。配对 bootstrap 按来源重采样 2,000 次。它描述固定训练模型的样本不确定性，不能替代多个训练随机种子。

新的 240 张确认图来自原 VisA test 分区，每个类别 10 张正常、10 张异常。封存前排除全部已记录评测来源及其 SHA256，同时与训练和验证分区隔离。确认集会用完当前测试分区中尚未评测的异常来源。本轮只生成清单，不运行它的模型预测；在下一次最终评测前需要固定模型与完整协议。

旧的 VisA 120 张与 MVTec 150 张预测已被查看，后续用作回归检查。基于它们的错误修改训练后，再次报告同集合表现时，应标为开发回归结果。

## 连续评分与误报阈值

为基础模型和本轮三个适配器增加同一套判断评分：固定图像、判断指令和 JSON 前缀，仅计算 `true`、`false` 对应 token 的条件对数似然，再在这两个候选中归一化。评分调用不接受真实标签；标签只供事后计算指标。候选的 token 边界、原生图像字段与共同前后缀必须通过校验。

报告 AUROC 和 average precision；归一化后的候选分数不称为已经校准的置信度。阈值只用验证集正常图的分数顺序统计量选择，使验证集的经验 FPR 不超过 5%，再将同一阈值应用到来源不相交的旧测试回归集。这个阈值不保证未来样本或跨数据集误报率也低于 5%。

## 交付边界

第一轮代码与结果归档保留。本轮使用独立的 prepared、configs、runs、evaluations、reports 子目录，以及冻结的运行源码与输入哈希。训练仍只保存适配器，不保存优化器状态；训练中断不能精确续训，须保留失败目录并另建运行。评测与评分支持经过配置、数据和适配器哈希校验的恢复。

本轮不改变采样策略、不增加裁剪输入、不调整视觉分辨率、不加入额外异常合成。结论限于有监督 VisA 自定义分区、单个训练 seed、单个全图和缺陷外接框任务。
