# 候选几何审计协议 v1

状态：已在 AutoDL 冻结并执行；结果属于已查看开发集工程诊断。

## 目的

验证 ROI/二次判定的共同上游瓶颈是否来自候选框几何。该实验只生成和评价候选框，不调用 Jev API，不训练模型，不修改既有冻结产物。

## 数据与坐标

- query：沿用已冻结的 120 张开发 query（60 正常、60 异常），仅作开发集诊断。
- 特征：既有 Teacher `square224` anomaly map。
- 坐标链：`square224 → 原图 → 448`，图像变换和边界裁剪使用既有 stage03 几何实现。
- 评价：待候选预测文件和 SHA 冻结后，才读取批准的开发 mask 做评价。

## 预注册候选规则

三种规则全部对同一 120 query 运行：

1. **union95 基线**：沿用既有 `map >= quantile(map, 0.95)`，把所有选中像素合并为一个 union bbox。
2. **connected95**：沿用同一 p95 二值图，按 8 邻域取连通域；选择平均 anomaly map 分数最高的连通域，若分数相同取面积较小者，再取其 bbox。
3. **peak56**：取 anomaly map 全局 argmax，以该点为中心生成 `56×56` 的 `square224` 窗口；窗口越界时平移回合法范围，再映射到原图和 448。

规则参数、tie-break 和坐标转换在服务器 preflight 中写入 protocol hash；读取 mask 后不得修改。

## 指标

主指标：60 张异常图的全异常 mean IoU。

次指标：

- 异常图 IoU≥0.5 比例；
- 异常候选覆盖率；
- 正常图出框率；
- 整图框比例；
- 候选面积分布；
- 与 union95 的逐图配对差异及 bootstrap 区间。

所有分母固定为 60 异常和 60 正常。不得只在被保留的候选或非整图子组上报告主结论；面积分层只能作为诊断。

## 决策门

具体工程门在读取本轮结果前写入 protocol，不把粘贴文本中的建议阈值当成既定事实。至少预先声明：

- 若候选仍大量退化为整图框，则停止付费 ROI/路由扩展；
- 只有候选质量改善且主指标与整图框比例同时达到预设门，才进入 DD gate 回顾；
- 若候选质量未改善，Jev 继续作为图像判断基线，不进入默认主链路。
