# 人工语义复核材料与收尾计划

日期：2026-11-11。沿用已批准的“完整语义核验需要人工事实标注”方向；本次只准备复核材料，不自行填充人的判断。

## 设计与范围

固定复用在线 pilot 的24个已看开发来源，不按缺陷类型、标签或分数补样。两位复核者先只看整图，记录可见异常与不确定性；完成整图判断后再看相同来源的候选裁片，记录该区域是否有缺陷、是否与整图一致及可见证据。候选不足、反光、分辨率不足应允许“不确定”。

采用 Markdown 图像目录及空 JSONL 表单，不新建 Web 应用、不安装依赖。图像提供448原输入；此标注只对应这个输入条件，不能代表原图可见性。公开复核材料使用中性编号，不包含原图类别、source ID、Teacher 训练状态、标签、mask、模型概率或选择动作。来源映射在材料包外单独保存，以便后续对齐。

两位复核者不得预先查看 mask、旧结果和他人表单。保留两份原始表单，分歧由第三人或复核会议裁决。描述只记可见形态，不根据单图猜测材质、维修史或故障原因。缺陷类别可用开放文本，不能把模型输出或路径名作为人工类别标签。

方法选择由执行者根据已有24图协议确定：自动mask代理已经只有2来源，不能拿它代填人工事实；额外训练或扩API在当前路由负结果下缺少依据。文档与空表单是可以立即交付的下一步。

## 执行清单

- [ ] 服务器核验 online contract 与24对 query/crop SHA，生成中性编号图像和两个分阶段目录。
- [ ] 为两位复核者各生成24项空表单，预填项仅限中性编号、图像路径和表单版本。
- [ ] 服务器检查48条表单状态均为 pending、无自动金标；材料包不含源ID、标签、分数和mask。
- [ ] 核验所有链接与图像 SHA，生成只供复核者使用的材料压缩包及独立来源映射。
- [ ] 整合固定FPR、三态、在线和空间诊断结果，生成逐文件交付清单。
- [ ] 人工完成两份表单并裁决分歧（等待实际人工，不由模型冒充）。
- [ ] 冻结人工事实标签后再定义/评估语义命题，另设新的互斥确认来源。

## 执行记录

Ruling：本轮交付位于现有独立实验目录，不改应用源码、不切换或重置用户工作分支。原冻结结果和报告保留，通过新增勘误解释文字歧义。

Ruling：confirmation 的历史完成信息只从已发布报告引用；本轮不打开任何新的确认数据，不据其调整三态或语义方法。

验收仅验证材料完整性和来源隔离；它不证明人工标签有效或模型性能改善。新的reviewer盲标是对结果隐藏的标注流程，不是新盲测数据集。
