# V12 Region-Ranked Recovery Compact2

## Purpose

This is an independent recovery implementation of the V12 industrial anomaly
detection pipeline. It preserves the V12 Region Ranker and DINOv2 dense
proposal design while fixing two operational problems: excessive memory during
reference calibration and disk exhaustion when serializing two large banks into
one cache.

## Model chain

```text
Official Train normal images
        |
        +--> DINOv2 ViT-B/14 at 1036 and 518 input scales
        |        |
        |        +--> reconstruction branch
        |        +--> category/view memory branch
        |        +--> pseudo-anomaly head
        |                    |
        |                    +--> dense anomaly proposal map
        |                               |
        |                               +--> connected components at multiple thresholds
        |                                          |
        |                                          +--> 22 region descriptors
        |                                                     |
        |                                                     +--> Train-only Region Ranker
        |                                                                |
        |                                                                +--> compact candidate mask
        +--> Train-only calibration and reference banks

Test A images --> same dense branches --> candidate ranking --> 448x448 masks
                                            |
                                            +--> image-level anomaly score
```

The Region Ranker uses area, compactness, peak/quantile response, threshold
persistence, branch agreement, foreground overlap, outline overlap and local
gradient descriptors. It can reject a view entirely; it does not force Top-1
and never converts a whole object silhouette into an anomaly mask.

## Recovery changes

- Reference banks are built one scale at a time with bounded reservoirs.
- Each bank is saved independently and can be reused after interruption.
- Pixel and image calibration are performed one scale at a time with bounded
  value reservoirs.
- The final reference is a small JSON manifest pointing to the independent
  bank and calibration files. This avoids a temporary second copy of an
  approximately 10GB PyTorch cache on the 50GB competition volume.
- Candidate rejection uses a Train-only threshold multiplier (`0.84` in the
  compact2 run) and a smaller relative margin. The dense map remains the
  source of pixel ordering; the ranker only selects compact regions.
- Memory budgets are compacted to `2048` per category/view and `8192` global;
  the underlying DINOv2 multi-scale design is unchanged.

## Compliance

Training, calibration and pseudo-anomaly construction use only official Train
normal images. DINOv2 and the existing generic branch checkpoint are used as
public generic model weights. No Test A labels, external anomaly datasets,
online APIs or external anomaly-specific weights are used.

## Output

The validated compact2 run produced 750 CSV rows and 3,750 grayscale 448x448
masks. The submission archive is generated by `run_v12_recovery.sh`; the
server deployment and read-only monitor are provided by:

- `deploy_v12_region_ranked_recovery_compact.sh`
- `check_v12_region_ranked_recovery_compact.sh`

The downloaded archive is kept locally as
`submission_v12_region_ranked_recovery_compact2.zip` and is intentionally not
added to Git as a generated result artifact.
