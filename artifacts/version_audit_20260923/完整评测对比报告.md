# v1–v5 全量 dev 评测对比

v1–v5 以及 v5-hard 均已完成；每个版本使用 3600 张视角。v1–v5 有门控和无门控共 10 组，v5-hard 另有同口径的 2 组结果。数据已同步到本地。

## 口径与限制

18 类，375 个记录中的样本组，1775 异常视角、1825 正常视角。所有版本图像顺序、标签、分类概率一致，逐图直方图像素数已校验。

所有版本使用 mean_w0.5 融合，输出 448×448 uint8 概率图；gate=0.5 拦截 p_yes<0.5 的图，gate=0 保留所有真实预测。固定阈值指标使用量化值≥128；AUROC/AP/F1max 使用全体像素直方图。异常 Dice/IoU/Recall 是异常视角宏平均，pixel Precision/Recall 是全体像素微平均，二者不可混用。

**v1 在这里也是统一 mean_w0.5 融合，不能直接当作历史 max 融合提交的复现。v4 使用 24000 step。** 此 dev 曾用于模型选择，属于已见类别的开发集；并非独立测试集，不能用绝对分数推断比赛榜单。历史 tune/holdout 也不能当作全新未见测试集。

## 测试集一致性核验

v1、v2、v3、v4、v5 **严格使用同一个测试集**：`artifacts/splits/fold1/dev_unbiased.parquet`。每个报告均为 3600 行；逐图结果的 `image_path`、`view_label`、`class_name`、`visual_group_id` 和 `p_yes` 顺序完全一致。测试集内容指纹（`image_path, view_label, mask_path, class_name, visual_group_id`）为：

`5324c35b47ae5f9d358fc2a783b12c9b45e52d372ea581135577ecfbcb70a36c`

因此 v1→v5 的差异可以归因于分割 checkpoint，而不是测试集抽样、标签或分类器概率变化。五版都使用 `mean_w0.5`、448×448、融合后一次 uint8 量化，并同时评测 gate=0.5 和 gate=0。

v5-hard 也使用同一路径和同一个 3600-view `dev_unbiased.parquet`，但它不在本次 v1–v5 汇总表中，因为它是另一个独立训练分支。v5-hard 的 checkpoint 是 `segmentation_qwen3_patch9_v5_hard_24000_r2/step24000.pt`；其结果归档在 `artifacts/full_dev_audit_20260923/v5hard/`。v5-hard 的 mean_w0.5 结果为：gate=0.5 时 AUROC/AP/F1max=`0.952637/0.840522/0.820780`，gate=0 时=`0.984774/0.871959/0.823936`。它与 v1–v5 可以做同测试集的横向比较，但应标注为 v5-hard，而不是普通 v5。

注意：这是开发集，不是全新独立测试集；历史训练和模型选择使用过相关 dev 信息，所以绝对分数适合做版本回归与问题定位，不应直接等同于官网榜单分数。

## 主要结论与改进优先级

1. **v5 无门控综合表现最好，但并非每项指标都第一。** F1max=0.830163、异常 Dice=0.787907、异常 Recall=0.807520；v4 无门控 AP=0.855263，略高于 v5 的0.855104，差距不足以单独宣称明确优势。
2. **去门控是召回与误报的取舍。** v5 异常空预测从177降至54，正常图非空预测从61升至171。应同时看漏检与正常图误报，不能只看 AUROC 的提升。
3. **v2 更激进。** 无门控 AUROC=0.982372，为所有配置最高；但628/1825正常图出现非空预测，F1max从0.800527降至0.794351。其异常空预测仅16张，说明响应覆盖广，但误报控制弱。
4. **v3 在本开发集未稳定超过 v2。** 无门控 Dice 0.718648 对0.756745，tiny Recall 0.603539 对0.714702。该结果仅适用于本次统一融合口径。
5. **v5 对小缺陷的改进最明显。** 相比v4，无门控tiny Dice从0.672674升至0.692872，Recall从0.718167升至0.764034，tiny空预测30降至17；large空预测21到22，仍需单独排查。
6. **下一轮优先查看具体错误来源。** v5无门控的jam_jar_model异常Dice仅0.626142，92张异常中28张空预测，占全部54张空预测的一半以上；优先核查标注、缺陷形态、裁切和空间响应。3_adapter有37张正常图分割误报，优先检查反光/纹理等正常结构，再决定hard-negative采样。分类器仍漏检165/1775张异常，分类器改进须另设版本和独立结果，不能归功于分割权重升级。

以上为观测结果和后续排查方向，不能仅凭聚合指标断定错误的视觉成因。建议在同一数据划分、同一阈值上做单变量消融，并保留逐图回归对照。tiny为原图缺陷面积占比(0,0.5%)，small为[0.5%,2%)，large为[2%,100%]。
