## 已经可以确定的结论

1. **必须将原生 Qwen 工业 SFT 与 AnomalyGPT 严格迁移分开。** 前者使用原生视觉塔和真实区域监督；本轮使用 ImageBind、保留的 decoder／PromptLearner，以及 Qwen 的语言部分。本轮没有正常参考分支和 PandaGPT 混训，属于简化迁移 pilot。
2. **旧像素指标计算口径有误，已经修订。** 旧实现将四层图拼成更多样本；应先平均四层，再对最终图计分。GPU 重现同一 frozen42 checkpoint 的旧值 80.8770% 与修订值 99.3631%。这是评测修正，不能表述为训练提高。修订后的图像标签取显式标签或 Yes/No 语义；像素 GT 继续使用 soft mask >0.3。
3. **初始化并非随机 decoder。** 服务器初始化与已下载的 AnomalyGPT 发布 VisA checkpoint 字节一致，SHA256 为 `a7e858586d9118c3322ff8ca3b60a8c7c521859ec8c1825e733df6666acab7d6`。完整上游训练来源清单仍未核验，不能宣称整个预训练链与评测来源完全隔离。
4. **旧 token accuracy 无法代表真实异常识别。** 没有发现 causal label shift 错位；旧汇总是按样本数加权的 batch token accuracy 均值，并非全局有效 token 的准确率。自由生成的真实异常召回才暴露了主要问题。
5. **16 steps 的实际数据覆盖很小。** 缓存有 48 个正常源图、96 个 variant，但 batch2×16 仅曝光 32 个 variant；seed42/43 分别涉及 27/28 个源图。seed42 未曝光 pcb4。三 seed 是训练随机性的描述统计，不能代表未见类别泛化。

## 已完成的真实结果

2,005 张固定来源＝925 正常＋1,080 真实异常，12 类。所有完整评测的来源、GT、类别和 JSONL hash 已核对；独立重算图像与分类指标的最大误差为 1.55×10⁻¹⁵。下表为百分比；Pixel AP 为 12 类等权宏平均。

| 组别 | 生成二类 Macro-F1 | 异常召回 | 正常误报率 | Pixel AP |
|---|---:|---:|---:|---:|
| 历史冻结 Qwen，3 seed 均值±样本 SD | 35.32±3.94 | 4.69±6.20 | 4.14±7.08 | 19.61±1.14 |
| 历史 Qwen LoRA，3 seed 均值±样本 SD | 37.93±5.79 | 6.82±6.55 | 1.98±3.34 | 19.57±1.03 |
| 匹配冻结 Qwen，**仅 seed42** | 31.42 | 8.15 | 9.41 | 19.11 |
| 匹配 Qwen LoRA，**仅 seed42** | 31.98 | 0.37 | 0.00 | 18.25 |
| 匹配 Vicuna-v1.1，**仅 seed42** | 32.57 | 0.93 | 0.11 | 18.42 |

始终回答“正常”的二类 Macro-F1 为 31.57%。匹配 LoRA42 在 2,005 图中回答 No 达 2,001 次；因此其 F1 不能解释为可靠检测。冻结 Qwen42 有 22.99% 无效回答，进一步限制了可用性。

真实 mask 前景仅占全部像素的 0.526%；异常图中位前景面积为 98/50,176 像素。Pixel AUROC 约 90% 时仍必须结合 AP 约 18%～21% 理解，不能直接写成定位成功。发布 decoder 的初始化 Pixel AP 为 20.99%；当前匹配 seed42 的三臂均未超过它。

历史组使用 max_tgt_len64，新匹配组为128；历史组不能与新组直接组成训练提升对照。新匹配三臂同 seed 共用 bridge 参数与显式样本顺序，但 PromptLearner 原本为 Vicuna 训练；共享 4096 维权重并不保证对 Qwen 有同等语义适配。不同 tokenizer 使监督 token 数和计算量也不同。

主集合保持固定，同时另做剔除这 8 张后的 CPU 敏感性检查：1,997＝917 正常＋1,080 异常。已完成的 10 项评测异常召回全部不变，生成 F1 只小幅变化。该检查不重算像素指标，也不能把已查看的集合重新变成独立最终测试集。本轮集合应一直称为开发诊断集。

## 下一步的执行顺序

1. 恢复 SSH 后先检查 `safe_state.json`、GPU 进程和 `safe_pipeline_resume.log`。若原作业仍运行，继续等待；若已退出，使用安全 runner 校验完整输出并续跑，保留所有 partial 和历史结果。
2. 补齐 32/32 项，再统一重新生成 `summary.json`、中文结果表和生成诊断。仅在三臂三 seed 全部通过控制审计后生成正式对照图。
3. 对固定 48 张已查看真实图运行异常图交换诊断。只交换送入 PromptLearner 的同类、相反标签图像的**预测异常图**；自身 global feature 和问题固定。检查 donor map、soft prompt 和候选 log odds 的变化，同时记录同条件重复推断的数值噪声。
4. **当前不建议直接扩大训练。** 如果定位图不同而 soft prompt 几乎相同，先查 PromptLearner；若 soft prompt 有明显变化而答案不变，先查语言投影、接口与文本监督。若训练后热图持续劣于初始化，下一轮先冻结 decoder，隔离语言对齐梯度，再讨论更大来源覆盖和更新预算。

该诊断只能测本次干预的敏感性，不能单凭交换后输出不变就认定语言模型完全忽略定位信息。完整三 seed 也不能用于排名 Qwen 与 Vicuna 的总体能力。
