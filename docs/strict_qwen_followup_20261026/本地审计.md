## 可复用审计工具

[audit_experiment.py](../../AnomalyGPT/followup_20261026/audit_experiment.py) 仅使用 Python 标准库，默认只哈希代码／配置／结果等元数据，tensor 文件仅记录大小。它不调用 `torch.load`，不读取 SSH 配置，不执行训练或推理；明显的凭据文件名被排除，运行配置只提取训练与初始化字段白名单。

```bash
python audit_experiment.py /absolute/path/to/strict_qwen_bridge_v0 \
  --output /absolute/path/to/audit.json \
  --train-split /absolute/path/to/splits/balanced_train.csv \
  --test-split /absolute/path/to/splits/balanced_test.csv
```

需要对 checkpoint 计算哈希时增加 `--hash-weights`。这会顺序读取权重字节，仍不会反序列化。`--scope all` 可扩展文件类型清单；默认 `metadata` 范围保留 tensor 的大小清单。

工具会检查 CSV 里的完整源图路径交集、各 split 内重复来源和类别／标签行数。normal/synthetic 两个 variant 共享 source 时的重复是预期现象，不能将 variant 行数视为独立 source 数量。相对路径与绝对路径若表示同一文件，需要先统一清单根路径；该工具不会依据文件名猜测跨目录对应关系。

本轮用临时 fixture 验证了路径交集、variant 重复、初始化字段提取、敏感字段排除、权重大小模式与权重 SHA256 模式。然后对本地旧代码目录完成了一次真实清单运行。未对训练或指标效果做新声明。
