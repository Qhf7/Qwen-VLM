主张：在整类留出下，接了 VLM 语义分支的分割模型，比同容量、同监督、同预算的纯 DINOv2 有更高的像素 AUPRO。 ｜必须能反驳的三个替代解释：①涨的是视觉不是语义 → A1；②涨的是参数 → 解码器容量对齐；③涨的是噪声 → 四折±std + group 配对 bootstrap。
前提事实：DINOv2 本身不是分割模型（特征 + 我们的解码器）；Qwen3-VL 的视觉/文本 token 不在对比学习空间，语言分支必须训练对齐桥。
