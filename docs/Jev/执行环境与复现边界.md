# 执行环境与复现边界

本附录的所有 Jev 图片判断、候选复核、动态路由、统计和图表，均在项目指定的 AutoDL 服务器执行；本机只负责代码/文档编辑、同步和结果查看。

- 仓库不保存服务器认证、API key、原始图片、模型权重、tensor cache、逐样本预测或人工复核原图。
- 报告中的 `/root/autodl-tmp/...`、`/tmp/...` 等路径是历史实验记录；换环境运行需要重新映射输入、权重和输出目录。
- confirmation240 已在最终系统、校准器、阈值和输入合同全部冻结后一次性查看；它现在是已查看结果，不能用于下一轮调参后再称盲测。
- Jev 的图片输入和 Box 属于厂商实验特性，需要额外 header；本附录的图片结论按研究原型处理，不构成生产就绪声明。
- 新增实验必须另立来源/字节互斥的数据角色，并继续遵守“先冻结协议、后读取标签”的顺序。

- 公开副本对脚本中的凭据前缀字面量做了最小化删除；历史报告中的该脚本 SHA 对应发布前版本，其余证据不变。
