# Jev 下一轮执行计划与采纳意见

更新日期：2026-11-11

## 结论

粘贴文本中的大方向可以采纳，但需要把“开发集工程诊断”和“新的科学验证”分开。当前三项 Jev 优先实验已经完成；下一轮不再扩大付费 Jev 路由，而是先验证上游候选几何和本地模型置信度是否已经足够解决问题。

推荐顺序为：

1. 完成人工复核包，冻结开发集 gold；
2. 在指定 AutoDL 服务器做无 API 候选几何审计；
3. 用已有 stage09 Qwen DD 分数做同条件、零成本门控回顾；
4. 只有前两步和第 3 步出现正信号，才建立本地可校准决策头；
5. 冻结最终方案后，另立来源互斥的新开发集和留出集，一次性确认。

本轮已执行阶段 A/B：`connected95` 将开发集全异常 mean IoU 从 0.089529 提升到 0.180475，并消除整图框；Qwen DD gate 回顾 AUROC 82.64%，新 duplicate 为 82.99%，Jev learned gate 为 77.08%。因此按停止规则暂停付费 Jev 二次判定和本地决策头训练，暂不进入新的确认实验。

## 阶段 A：人工复核与无 API 候选审计

这两项可以并行，均不需要新增 API；人工复核需要两位复核者，候选审计在指定服务器执行。

### A1. 人工复核包

- 两位复核者独立填写整图和候选字段，`uncertain` 与无法判断必须保留，空值不能当作 `no`。
- 逐项做分歧裁决，生成冻结的 `gold.jsonl`，记录 24/24 来源、两人记录数、裁决数、Cohen's κ 或等价一致率及全部分母。
- 先评价整图“可见异常”，再评价 13 个 eligible 候选的区域标签；两者分开统计。
- 只能做已看开发集的一致性和误差诊断，不能升级为新盲测或泛化结论。

当前状态：`human_completed=0`，材料仍为 `prepared_waiting_for_human_annotation`。

### A2. 候选几何审计

在服务器上固定坐标链 `square224 → 原图 → 448`，预先写入候选规则、主指标和停止门，再读取已有开发标签。建议比较不超过 2–3 种规则，例如：

- 连通域加面积约束；
- top-k 局部窗口；
- 已有 Qwen region 模型框（若现成产物可直接使用）。

主指标固定为：全异常 mean IoU、IoU≥0.5 比例、整图框比例、异常覆盖率、正常出框率。不要根据 120 张已看结果反复改 quantile 或面积阈值。

验收门应在读取新规则结果前冻结；粘贴文本中的 0.20/20%/80% 可作为待讨论候选，不是当前既定标准。若候选仍然大量退化为整图框，应停止 ROI/路由线的付费扩展，把 Jev 保留为图像判断基线。

## 阶段 B：Qwen DD 门控回顾

使用 `stage09_qwen_matched/scores.jsonl`，只做离线回顾，不发起 API、不做 GPU forward：

- 样本固定为在线 pilot 的同 24 张图；
- 候选固定为同一 eligible 集合，`K=8`；
- Qwen DD 使用已有 `anomaly_log_odds>0`，不在 24 张标签上重新选阈值；
- 与 Jev gate、new duplicate、同 K 随机使用同一 image-label proxy 统计；
- 报告 AUROC、Recall、FPR、候选保留数和共同成本口径，并明确这是回顾性 proxy。

判断规则：如果 DD gate 不差于 Jev gate，就没有为 gate 单独支付 Jev 调用费用的理由；如果三者都接近，路由问题应停止，转向候选几何或整图判断。只有出现预先定义的稳定正信号，才进入阶段 C。

## 阶段 C：本地可校准决策头

仅在阶段 A/B 保留正信号后启动，并另立新协议：

- 特征预注册为 Qwen DD/base log-odds、候选面积、Teacher 分数、候选与整图的一致性等；
- 首版只拟合 logistic，暂不使用高容量 GBM；
- calibration 与 holdout 必须 source/byte-disjoint，不能复用已看 confirmation240；
- 同时保留 duplicate、Jev gate 和 Qwen DD gate 基线；
- 预注册 AUROC、固定运行点 Recall/FPR、人工复核量、API 调用量和成本估计；
- 只有在独立 holdout 上至少一项核心指标稳定优于基线，且配对区间不跨 0，才考虑继续扩大实验。

## 阶段 D：新的确认实验

阶段 C 的模型、候选规则、阈值、K、拒答规则和成本口径全部冻结后，另选与训练、开发和已查看 confirmation 来源/字节互斥的新来源，一次性运行。优先使用剩余 VisA 来源；MVTec 作为单独跨域实验，不能混成同一结论。

确认报告至少包括图像级 AUROC/AP、固定运行点 Recall/FPR、候选 IoU、整图框比例、调用数、延迟和可核算的成本。confirmation240 只作为历史结果索引，不再用于选型。

## 停止规则

这些规则是下一轮实验前要冻结的工程门，不是对未来数据的统计保证：

1. 候选规则若仍显示严重整图退化，停止 ROI/路由付费扩展；
2. Qwen DD gate 若不劣于 Jev gate，停止单独 Jev gate；
3. 本地决策头若在新 holdout 上不优于 duplicate 或 Qwen gate，停止路由线；
4. 人工复核若一致率低或 `uncertain` 占比过高，语义方向降级为定性分析，不报告视觉事实准确率；
5. 没有真实文本数据时，不启动 Choice/Score 文本路线。
