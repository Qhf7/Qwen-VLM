# 大模型基座算法岗位：项目经历

依据截至2026-11-04完成的实验整理。建议用于多模态基座、SFT、参数高效后训练及训练算法方向；项目周期、单位和个人职务按真实情况填写。

## 可直接用于简历的版本

**Qwen3-VL 多模态适配与后训练优化**  
面向工业异常检测，研究跨模态接口适配、参数高效微调与任务目标优化。  
技术栈：PyTorch、Transformers、PEFT/LoRA、Qwen3-VL、ImageBind、SFT、成对排序、混合精度训练  
项目地址：https://github.com/Qhf7/Qwen-VLM

- **跨模态接口适配：** 设计CLS投影与18-token异常图桥接接口，将AnomalyGPT语言骨干迁移至Qwen3-VL-8B；固定视觉前端、重新训练桥接并开展三seed配对实验，开发验证Image AUROC由88.97%提升至92.58%。
- **参数高效微调：** 在72个语言q/v模块注入LoRA，仅更新383万参数，开发验证AUROC达到93.70%；进一步采用桥接与LoRA双学习率联合训练，AUROC达到94.03%、生成Macro-F1达到86.62%。
- **训练目标优化：** 构建答案CE与同类别正负样本排序联合目标，直接优化首答案Yes−No分数，并通过训练梯度范数标定损失权重；匹配初始化、采样及损失归约，开发验证AUROC由93.53%提升至94.73%，同时评估召回、误报与跨域退化。
- **结构化指令微调：** 将训练mask转换为归一化边界框及九宫格位置监督，开展语言LoRA结构化SFT，建立语法、几何与位置一致性评测；外部1575图上的平均严格结构有效率由64.13%提升至91.96%，并分析输出一致性与定位精度的差距。
- **训练工程与评测：** 打通自定义embedding梯度链路，采用BF16基座与FP32 adapter，完成增量权重保存、独立重载及adapter关闭验证；24GB单卡LoRA方案峰值约16.37GiB，完成21组冻结外评及33075条预测复算，分析排序与生成决策的泛化差异。

以上AUROC/F1为自定义监督VisA开发val380上的三seed均值；结构有效率来自MVTec外部1575图。LoRA-only的383万参数不包括联合方案额外更新的约1.116亿桥接参数。外部33075条预测来自同一1575图上的21次模型评估，不是33075张独立图像。

## 一页简历压缩版

**Qwen3-VL 多模态适配与后训练优化**  
PyTorch / Transformers / PEFT / LoRA / SFT / Pairwise Ranking

- 完成AnomalyGPT→Qwen3-VL-8B语言骨干迁移，构建CLS＋异常图token接口；固定视觉前端进行三seed对照，开发验证AUROC由88.97%提升至92.58%。
- 实现383万参数语言LoRA及桥接/LoRA双学习率联合训练，开发验证AUROC分别达到93.70%与94.03%；处理自定义embedding梯度、混合精度及adapter重载，LoRA训练峰值约16.37GiB。
- 设计CE＋同类别成对排序目标及匹配采样控制，开发AUROC由93.53%提升至94.73%；完成结构化SFT及21组冻结外评，量化结构一致性、定位误差和排序目标的跨域退化。

## 偏低显存训练岗位的替换条目

以下来自更早的原生Qwen3-VL路线，采用独立数据划分、训练预算和评分协议；可替换正文的结构化能力条目。若使用，应在技术栈加入QLoRA、bitsandbytes，保持两条路线的实验指标分别表述。

- **低显存VLM训练：** 基于原生Qwen3-VL-8B实现NF4双重量化与q/k/v/o LoRA，结合梯度累计、梯度检查点及assistant-only CE，在24GB单卡更新1534万参数；固定768个源图及曝光顺序比较判断/定位/混合任务，同域120图开发验证AUROC由量化底座82.39%提升至94.56%（单seed）。

此条不能将NF4、梯度检查点或1534万参数归到后续BF16 q/v LoRA实验；后者未使用量化和梯度检查点。120图上的94.56%与后续380图上的94.03%不作同协议比较。

## 岗位匹配与面试重点

| 岗位关注点 | 项目证据 | 面试展开 |
|---|---|---|
| 多模态架构与接口 | 语言骨干迁移、CLS/异常图token；另有原生Qwen接口核验 | 视觉embedding如何接入LLM；原生路线的MRoPE、DeepStack、mask及KV cache一致性 |
| SFT与PEFT | q/v LoRA、BF16/FP32、分组学习率；早期另有QLoRA | 更新范围、梯度流、FP32 adapter原因、显存构成及checkpoint绑定 |
| 训练目标与实验设计 | CE＋可导首答案排序、训练梯度范数标定、Cpair匹配控制 | 为什么不用no_grad评分函数训练；为何ranking必须对Cpair；token-mean归约影响 |
| 多模态能力扩展 | mask到bbox/位置的结构化SFT | 正常空框、坐标归一化、全异常分母、格式正确与框重叠质量的区别 |
| 泛化与评测 | 三seed、冻结外部21组、原始预测复算、独立回载 | AUROC与生成F1区别、跨类分数可比性、阈值/误报取舍、数据划分边界 |

一分钟介绍：

> 我围绕Qwen3-VL-8B做工业领域多模态后训练。先固定视觉前端迁移AnomalyGPT语言骨干，用三seed对照验证语言替换；随后实现383万参数LoRA与桥接/语言双学习率联合适配，将开发验证AUROC提高到94.03%。目标层面，我实现了CE加同类别成对排序，使用训练梯度标定损失尺度，并用匹配采样控制避免混淆算法收益。工程上处理自定义embedding梯度、混合精度和增量checkpoint，最后完成21组冻结外评。外部结果发现排序收益未复现、结构一致性也不等于定位准确，因此我能明确解释收益条件、失败原因假设与下一步控制实验。

## 面试需能解释的结果边界

- 排序实验开发FPR由2.52%升至6.20%；外部AUROC相对Cpair下降0.6143个百分点、生成F1下降1.7791个百分点。排序目标不是DPO、PPO或RLHF。
- 结构化继续训练同时增加mask监督、目标token和曝光；外部全异常框IoU .071108→.069815，严格结构有效率不能称定位准确率。
- 原生ROI工具接口和五臂评测已完成，但planner380次全部answer、真实crop0。该实验可用于讲对照与失败分析，不作自主Agent收益条目。
- 当前证据对应已有基座的领域后训练；项目没有开展大规模预训练、多机分布式预训练或经验证的复杂推理强化。
