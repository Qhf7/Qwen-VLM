# Qwen-VLM 项目成果与创新总结

> 整理日期：2026-11-05。实验进展以现有2026-11-04最终报告为准；本次整理没有新增训练、模型推理或外部测试。本文汇总项目成果、量化指标、方法与工程贡献，以及面试和简历中应保留的结论边界。

项目最扎实的成果有三项：**重建可靠的异常定位前端；验证Qwen语言骨干迁移与LoRA后训练的同域收益；完成覆盖跨域、结构化输出和工具调用的系统评测。** 项目创新主要体现在跨模态接口、分阶段适配、目标函数对照和可复核评测体系。LoRA、QLoRA、蒸馏等基础方法来自已有研究，当前没有学术首创或公开SOTA的充分证据。

## 1. 先明确指标与比较口径

| 概念 | 本文含义 | 不能等同于 |
|---|---|---|
| Image AUROC | 连续异常分数将异常图排在正常图前面的能力 | 分类准确率、固定阈值召回 |
| AP | Average Precision，异常检索的精确率与召回综合指标 | PR曲线梯形面积；不同基率数据上的可直接排名数字 |
| 生成Macro-F1 | 全部图像上正常/异常两个标签F1的平均 | 产品类别F1的等权平均 |
| Recall | 真实异常中被回答为异常的比例 | 模型整体准确率 |
| FPR | 真实正常中被回答为异常的比例 | 异常漏检率 |
| Pixel AUROC/AP | 每像素异常分数的排序/检索质量 | 图像级判断、框IoU |
| 严格结构有效率 | 输出满足语法、schema、坐标和内部一致性要求 | 框定位正确率 |
| pp/百分点 | 0–1指标差乘100，例如0.9258到0.9370约+1.12pp | 相对增长百分比 |

修复后主线采用自定义有监督VisA：train9985、val380（正常172/异常208）、历史test456。训练包含真实异常及mask，val用于多轮开发与checkpoint选择，456图已参与历史开发；结果不能直接与官方normal-only无监督基准比较。

Phase1及后续正式语言实验使用预定seeds42/43/44，三seed不是三套独立图像，也不自动构成统计显著。独立原生QLoRA和ROI等探索另有协议，不能与主线数字混为一个排行榜。

## 2. 成果一：异常定位管线得到实质修复

### 2.1 解决了什么问题

项目在相关旧定位训练路径发现并修复：

1. **mask前景被清零**：VisA前景索引1–8，旧路径先除255再大于0.3，会清除前景；改为原始值>0。
2. **mask路径映射错误**：`.JPG`图像对应`.png`标注，严格定位文件；异常mask缺失直接报错。
3. **RGB/mask几何错位**：图像与标签统一square224，RGB bicubic、mask nearest。
4. **token/batch轴错误**：ImageBind原始`[257,B,1280]`转为`[B,256,1280]`，去掉CLS，核验逐图空间输出。
5. **损失数值问题**：使用稳定BCEWithLogits Focal＋Dice，避免sigmoid后clamp造成梯度截断。
6. **权重与运行不一致**：strict加载，记录pipeline、decoder和cache SHA，训练/评测路径统一。

这些问题不能未经链路核对就泛化为每个旧实验都存在全部bug；旧2005图诊断和合成mask路径有不同实现与语义。

### 2.2 量化改善

重新训练**5,409,537参数BigDec**，seed42，1200更新×batch4＝4800次曝光，训练本身约302秒。在同口径历史456图上：

| 指标 | 旧linear定位权重复评 | 修正后BigDec | 变化 |
|---|---:|---:|---:|
| 类别宏Pixel AUROC | 80.5068% | **97.6802%** | **+17.1734pp** |
| 类别宏Pixel AP | 3.9255% | **39.3868%** | **+35.4613pp，约10.03倍** |
| 前景加权Pixel AUROC | 82.4368% | **97.3015%** | +14.8647pp |
| 热图P99 Image AUROC | 54.0228% | **81.7053%** | **+27.6825pp** |

验证覆盖：**12项CPU回归测试**；732训练异常、208验证异常、260历史测试异常mask在修正缩放后均保留前景。

**技术意义：**建立了足够可靠的定位teacher，避免把数据/实现缺陷误判为预训练表征的能力上限。整体改善同时包含架构、预处理和训练变化，尚未通过逐项消融分离各修复贡献。

证据：[修复报告](../repair_20261103/REPAIR_REPORT.md)、[定位源码](../repair_20261103/code/dec_big.py)、[数据管线](../repair_20261103/code/visa_pipeline.py)。

## 3. 成果二：Qwen语言骨干迁移取得三seed正向证据

### 3.1 方法设计

固定共同ImageBind＋BigDec，从图像提取1024维CLS与224×224预测异常图：

```text
CLS1024 → Linear → 1个4096维token
异常图224² → PromptLearner → 9个base＋9个map-adaptive tokens
合计19个soft tokens → 目标LLM语言部分 → 分数与回答
```

分别为Vicuna和Qwen重新训练bridge，共111,614,904参数；两语言原权重BF16冻结，两边不使用Qwen原生视觉塔。同seed共享可比较的新bridge初值、teacher缓存和采样顺序，各1500更新、6000曝光。

**创新价值在可控制的迁移接口与实验设计**：相同隐藏维度不代表嵌入语义一致，不能直接沿用原Vicuna桥接就期待Qwen读懂。

### 3.2 主要结果

| 指标，三seed均值 | Vicuna | Qwen | Qwen−Vicuna |
|---|---:|---:|---:|
| Image AUROC | 88.9684% | **92.5779%** | **+3.6095pp** |
| Image AP | 91.9143% | **94.1595%** | +2.2451pp |
| 生成Macro-F1 | 81.6122% | **84.5672%** | **+2.9550pp** |
| 异常Recall | 66.6667% | **71.9551%** | +5.2885pp |
| 正常FPR | 0% | 0% | 该val上保持不变 |
| 生成invalid | 0% | 0% | 保持不变 |

| Seed | Vicuna AUROC | Qwen AUROC | 配对差 |
|---|---:|---:|---:|
| 42 | 90.4643% | 95.8659% | +5.4017pp |
| 43 | 87.9263% | 89.3266% | +1.4004pp |
| 44 | 88.5146% | 92.5411% | +4.0264pp |

三个seed的AUROC均正向；AUROC样本SD为Vicuna1.3285pp、Qwen3.2698pp，Qwen波动更大。生成F1仅两个seed提高，seed43略降。

**可支持结论：**共同视觉证据、重新学习接口和当前训练协议下，Qwen语言部分比Vicuna得到更好的同域开发排序表现。这个阶段没有训练LLM内部LoRA，也不是直接零训练替换的收益。

证据：[Phase1结果](../migration_20261103/PHASE1_RESULTS.md)、[协议](../migration_20261103/PHASE1_PROTOCOL.md)、[语言接口](../migration_20261103/code/migration_language.py)。

## 5. 成果四：构造匹配排序目标，并识别跨域负迁移

R增加监督式pairwise ranking，使同类别异常图分数高于正常图：

```text
s(x) = logit(Yes) − logit(No)
L_rank = softplus(−(s_anomaly − s_normal))
L = L_CE + λ·L_rank
```

设置严格匹配的Cpair：相同A起点、同类正负pair序列、micro2×accum2、同CE归约，仅去掉ranking。λ用16个train-only pair的初始梯度范数比标定，median14.06366，经预先clamp[0.01,1]后取1。

| 开发指标 | Cpair | R | R−Cpair |
|---|---:|---:|---:|
| AUROC | 93.5334% | **94.7348%** | **+1.2015pp** |
| 生成F1 | 86.0004% | **87.1828%** | +1.1825pp |
| Recall | 76.6026% | **81.7308%** | +5.1282pp |
| FPR | 2.5194% | 6.2016% | **+3.6822pp** |

R是本批二分类方案中平均开发AUROC最高的方案，但冻结外部评测中，相对Cpair的AUROC下降0.6143pp、生成F1下降1.7791pp、FPR增加5.6973pp；外部F1三seed均降。

**贡献是训练目标、匹配控制与失效诊断。** 当前R不宜作为跨域最优方案；该目标没有reference policy、chosen/rejected回复或在线reward优化，不是DPO/RLHF。

证据：[进阶协议](../migration_20261103/advanced_20261104/PROTOCOL.md)、[开发分析](../migration_20261103/advanced_20261104/ANALYSIS.md)、[外部分析](../migration_20261103/advanced_20261104/EXTERNAL_ANALYSIS.md)。

## 6. 成果五：结构化SFT显著提高输出遵循，分离格式与定位能力

S从同seed原C best继续**同一个q/v adapter**，使用train mask生成Yes/No、union bbox[0..1000]及九宫格位置作为答案监督；bridge和语言原权重冻结，新增500步/2000曝光，没有ranking项，也不叠新adapter。Cstructured是C权重仅换同样结构化prompt的控制。

| 三seed均值 | 开发Cstructured | 开发S | 外部Cstructured | 外部S |
|---|---:|---:|---:|---:|
| AUROC | 89.9975% | **93.9489%** | 69.9067% | **71.7814%** |
| 生成Macro-F1 | 82.1152% | **84.1060%** | 66.7084% | 67.0401% |
| 严格结构有效率 | 84.9123% | **95.9649%** | 64.1270% | **91.9577%** |
| 全异常平均框IoU | 0.030993 | 0.068755 | 0.071108 | 0.069815 |
| 全异常IoU≥0.5 | 0.009615 | 0.022436 | 0.036066 | 0.015779 |

外部严格结构有效率提高**27.8307pp**，AUROC提高1.8747pp且三seed均正。但外部生成F1仅seed44提高，框IoU没有提高。严格失败还包含location与自身bbox中心不一致，不能全称为JSON语法失败。

全异常定位分母包含No、无效和缺框，均计0，避免只统计成功出框的偏差。固定teacher-map框的外部IoU为0.224989，高于S的0.069815；但无条件teacher正常出框率100%，不能当作可部署检测器。

**可称结构遵循和结构化监督流程的成果，不能称精确空间定位突破。** S同时增加监督、token长度和训练曝光，缺少完全同曝光继续binary CE等单因素控制。

证据：[结构化协议](../migration_20261103/advanced_20261104/STRUCTURED_PROTOCOL.md)、[最终报告](../migration_20261103/advanced_20261104/FINAL_REPORT.md)、[外部结构诊断](../migration_20261103/advanced_20261104/EXTERNAL_STRUCTURED_DIAGNOSTICS.md)。

## 7. 独立原生Qwen QLoRA与ROI成果

### 7.1 原生QLoRA验证领域后训练价值

| 方案 | 验证AUROC | AP |
|---|---:|---:|

| RR：两次区域 | 91.49% | 93.01% |
| DD：两次判断 | **94.56%** | **95.26%** |
| RD：区域＋判断 | 92.01% | 93.54% |

### 9.3 工程贡献与验证范围

实现了目标模块及optimizer参数身份核验、有限非零梯度检查、LoRA首步/第二步A梯度检查、BF16底座与FP32 adapter控制、冻结bridge SHA、原子保存、标准PEFT导出、独立进程回载和adapter关闭恢复起点。正式C fresh检查的首答案分数最大绝对误差为0，原始生成一致。

SHA绑定源码、输入、权重和策略，raw可复算summary；这些检查提升身份和统计可信度，不证明算法一定泛化。本机result-only复算与服务器历史权重bytes/fresh验证分别记录；A原桥接run元数据SHA未在原freeze单独预绑定的来源限制保留。checkpoint未保存完整optimizer/scheduler，不能精确断点续训。

证据：[最终审计](../migration_20261103/advanced_20261104/FINAL_EVIDENCE_AUDIT.md)、[最终报告](../migration_20261103/advanced_20261104/FINAL_REPORT.md)、[工具分析](../migration_20261103/advanced_20261104/TOOL_ANALYSIS.md)。

## 10. 哪些可以称“创新”与“突破”

| 级别 | 可以主张的内容 | 证据与适用范围 |
|---|---|---|
| 已验证性能成果 | 共同teacher下Qwen语言迁移、后续383万LoRA同域改善 | Phase1及C三seed；开发验证，需伴随FPR |
| 项目方法设计贡献 | 共同视觉证据＋新桥接的受控迁移；分阶段桥接/LoRA/联合适配 | 接口与训练分支实现，不能称全新LoRA算法 |
| 训练目标与研究设计贡献 | Cpair/R匹配排序；S结构化监督；分开评排序、生成、schema、几何 | 有益与不利结果均保留，未证明跨域全面增强 |
| 工程贡献 | mask/几何/轴修复，dtype/梯度/参数身份、回载、冻结外评 | 可复核源码和审计，不等于生产部署 |
| 尚未成立 | 原创底座预训练算法、公开SOTA、精确空间理解突破、自主工具收益、跨域低误报 | 当前没有足够支持证据 |

**不能画成逐次继承权重的“Vicuna→Qwen→C→D→R”累计训练链。** Phase1分别重训新bridge；C、D、Cpair/R各从A出发；R只应与Cpair作目标归因；只有S从C best继续同adapter。

## 11. 适合面试与简历的表达

### 11.1 一句话成果

> 围绕Qwen3-VL-8B开展工业异常检测的跨模态迁移与后训练，修复定位前端，在共同视觉teacher下将语言骨干开发AUROC由88.97%提升至92.58%，进一步仅训练383万q/v LoRA参数达到93.70%，并通过3.3万条冻结外评识别排序负迁移、误报与空间信息保留不足。

### 11.2 项目经历条目

- **跨模态迁移：**保留ImageBind/BigDec，以CLS投影＋18个map soft tokens接入Qwen语言骨干，重新训练桥接；设计同初始化、采样、预算的三seed配对，使自定义监督VisA开发AUROC由88.97%提高至92.58%，生成Macro-F1由81.61%提高至84.57%。
- **参数高效后训练：**在36层72个q/v模块实现r8 LoRA，冻结视觉与bridge，仅更新383万参数；相对起点AUROC+1.12pp、生成F1+1.61pp，并设置同曝光bridge延续对照，完整报告召回与误报取舍。
- **目标与评测研究：**实现低LR联合适配、匹配CE/ranking和mask监督结构化SFT；结构化外部有效率64.13%→91.96%，同时记录框IoU未改善和ranking域外退化，避免将格式与同域收益等同于泛化能力。
- **复现工程：**完成标签、几何与特征轴修复、FP32 adapter/冻结与梯度审计、PEFT导出及独立进程重载；冻结7模型×3seed×1575图外评，共33,075条预测复算。

### 11.3 面试时应该主动解释的限制

1. 当前主要是领域适配和后训练，未从零预训练8B、未全参更新LLM、未进行DPO/RLHF。
2. 主线train含真实异常与mask，自定义开发集不能与normal-only论文数字直接比较。
3. 三seed与fresh检查都没有增加独立图像，不能替代新留出确认。
4. 外部FPR约61%–72%，当前不支持生产部署结论；S格式有效不代表定位准，工具合法action不代表有用调用。
5. 继续研究应优先保留空间的patch/map接口、独立坐标头、同曝光CE控制和新校准/确认数据，不能在已看外评上继续调参后仍称盲测。
