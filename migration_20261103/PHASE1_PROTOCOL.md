# 第一阶段：固定定位器，比较语言骨干迁移

目标是比较同一定位输入下 Vicuna-7B 与 Qwen3-VL-8B 的语言模型部分。两臂均不使用 Qwen 原生视觉；本阶段只改变语言骨干及其必要的分词器/对话模板。相同图片曝光不等于相同 token 数或计算量，应同时记录实际序列长度、时间和峰值显存。

两臂重新初始化 PromptLearner 与 ImageBind CLS→语言空间的投影，不加载与 Vicuna 配套的旧提示/投影。seed42 下保存并共享可比较模块的同一初始化张量；语言骨干冻结且以 BF16/eval 运行，ImageBind 与修正后的定位 decoder 全部冻结/eval。训练参数仅为重新初始化的 PromptLearner 和投影。若 BF16 全骨干在 4090D 24GB 上超出显存，应先记录阻塞并调整共同资源配置，不把一臂量化、一臂 BF16 的结果解释为纯骨干效应。

共同缓存含 `pipeline_version`、`decoder_sha256`、`items`（每项 path/category/label/split）、`cls[N,1024]` 与 `maps[N,224,224]`；特征和概率图均保存 float32，避免低概率截断。记录缓存哈希、decoder 哈希、代码版本、特征布局及原始数据清单。使用同一修正图像/mask处理和同一冻结定位器。所有路径必须唯一，train/val 不重叠；发布初始化或上游权重若存在未核实训练来源，应明确保留该边界。

协议为有监督自定义 60/20/20：train 9,985 张（正常9,253/异常732），val 380 张（正常172/异常208）。它使用真实异常训练，不能标作论文官方无监督协议。先运行 seed42：每臂1,500次更新、每更新有效图像数4，共6,000次图像曝光。可采用 microbatch=4、accum=1，或 microbatch=1、accum=4；最终配置以各臂 `run.json` 为准，匹配对照使用同一批次与累积设置。两种设置曝光相同，但不同长度答案的token均值损失权重及浮点梯度不保证逐位相同。预先生成并保存共同顺序，正常/异常各3,000次，按类别池内采样后打乱；重复曝光不计作新增独立源图。固定优化器、学习率、调度、损失、梯度裁剪与短答案监督，保持两臂一致。

每250次更新评测全部380张val，末步也评测。用标准 sklearn 图像 AUROC 选择 best；并列按较早检查点保留，最终另存 final。只保留 best/final；按约447MB/检查点为 PromptLearner及投影预留磁盘。保存 seed、共同顺序哈希、更新步数、pipeline/decoder/cache哈希和完整训练配置。两臂独立串行运行，不并发争用 GPU。

选择阶段不读取test预测或test指标，不用test选择检查点、提示词、损失、控制条件或超参。历史456张测试图已反复用于开发，不再称未查看确认集。正式结论需另设未查看来源；若另外报告历史开发集，应明确其角色。

主要指标分别报告：候选 Yes−No 分数的图像 AUROC/AP，以及零阈值（score>0为Yes）的accuracy、二类macro F1、异常recall和正常FPR。自由生成另报accuracy、macro F1、recall、FPR和invalid_rate，不能用候选评分替代生成结果。生成解析只接受去除空白和完整前置`<think>...</think>`后开头的独立Yes/No；允许已打开think语境留下的开头`</think>`。不搜索句中任意yes/no，未闭合think或结论前有其他正文均无效。invalid保留在全体accuracy分母，作为其真实类别的FN进入二类macro F1；FPR只统计正常图中明确Yes，须结合invalid_rate解读。另报按产品类别等权的指标和参与均值的类别数。

seed42先验证两臂数据/梯度/保存加载一致、损失有限、小样本能拟合、短答案解析和候选打分位置正确，再按相同协议补43/44。不得只挑最好seed。正式三seed报告均值及样本标准差，避免把单次波动当收益。

map干预仅做诊断：同类别相反标签donor-map交换保持自身CLS/问题不变，donor允许复用但不能配对自身、同一路径或跨split；标签仅用于构造诊断对照，不进入推理算法或提示。空间shuffle保持每图像素值多重集合完全相同但改变位置；常量图无法形成有效位置干预，应报告无效而非假称成功。real/zero/random、donor和shuffle分别检验不同问题，内容敏感性不能单独证明定位正确或检测收益。
