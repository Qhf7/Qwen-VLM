# ROI工具阶段分析：工程闭环完成，当前模型未选择裁剪

日期：2026-11-04。依据已同步本地tool_preflight/tool_val的run、predictions和后验audit，独立汇总重算完成。本文没有启动GPU、修改提示或训练/evaluator，也没有读取正在运行的外部模型结果。

## 直接结论

完整val380上，planner **380/380次输出完全相同的合法JSON：{"action":"answer"}**，schema错误0，真实crop调用0。正常172张和异常208张均无调用，所有12类别都相同；8张工程预检也为8个answer。模型没有输出任何坐标，因此不存在可分析的自主坐标分布，也没有展示自主裁剪或利用自己选择的局部证据的能力。

程序按冻结协议对未调用的model_tool提供原图副本，维持最终392视觉token预算。这是系统执行的预算控制，不是模型主动调用第二张图。model_tool与duplicate_original在380/380张上Yes/No logits、score、生成token和原始答案完全一致；两者的工具状态文字、prompt长度和实际双图内容也相同。模型臂没有产生独立于副本控制的行为增量。

该结果是完整、合法的负结果，不是schema/API失败。原生Qwen与processor、BF16、单图/双图grid和token等工程门禁通过；中心和随机裁剪臂各真实执行380次crop，说明执行器可运行。不能为展示调用而回头更改本轮提示、强制crop、删去answer样本或仅报告挑选案例。
