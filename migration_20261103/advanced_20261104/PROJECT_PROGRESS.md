## 可直接使用的项目简历

**项目名称：基于 AnomalyGPT 与 Qwen3-VL-8B 的工业异常检测及参数高效适配**

技术栈：Python、PyTorch、Transformers、PEFT/LoRA、ImageBind、Qwen3-VL、多模态适配、实验评测。

- 实现 AnomalyGPT 向 Qwen3-VL-8B 语言骨干迁移，构建 CLS 投影与18-token异常图跨模态接口；在相同视觉前端、采样及桥接参数的三 seed 配对实验中，将自定义监督开发验证 Image AUROC 从88.97%提高至92.58%。
- 在语言 q/v 层实现 r8/alpha16 LoRA 领域 SFT，仅更新383万参数，将三 seed开发验证 AUROC 提高至93.70%、生成 Macro-F1 提高至86.17%；进一步实现1.116亿参数桥接与LoRA的双学习率联合适配，当前训练/预测复算得到94.03% AUROC、86.62%生成F1，独立重载验收进行中。
- 建立起点/桥接延续/语言LoRA/联合适配的配对对照，联合评估排序、生成、召回、误报与资源成本；实现参数冻结和梯度审计、增量权重身份绑定，并完成历史B/C的独立进程重载及关闭adapter恢复起点验证，在24GB单卡上完成C约16.37GiB、D约17.68GiB训练峰值的可复核实验。

以上适用于当前进度披露。正式投递时，如果 D 独立重载仍未通过，可在第二条保留已验收的 C 数值，把 D 简化为“实现双学习率联合适配并完成三seed训练，验收中”。第三条中的独立重载和关闭adapter验证指已完成的历史B/C；D新增检查仍待完成。未完成的排序、结构化回答和工具阶段不写成已取得效果。

面试一段版：我先固定工业视觉特征和桥接结构，隔离语言骨干迁移的作用，再用同seed配对对照区分额外训练、语言低秩更新和桥接/语言联合适配。语言LoRA只更新383万参数，已经有三seed开发验证和独立重载证据；双学习率联合适配当前有小幅一致AUROC/AP与生成F1增量，并降低平均误报，但仍在完成独立检查。我的主要技术工作在自定义inputs_embeds梯度接入、FP32 adapter/BF16基座、分组优化、增量checkpoint身份绑定及可复核评测；现有固定Yes/No监督不足以证明复杂推理能力。
