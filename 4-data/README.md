# 真实训练图片查看目录

本目录只包含从 fold1/train 中复制的原始图片，每个零件类别各选取代表图片，未进行 CutPaste、NSA 或其他数据增强。

子目录含义：

- `real_anomaly`：数据集中标注为异常且该视角有真实 mask 的图片。
- `normal`：正常零件图片。
- `hard_normal`：正常视角中边缘、纹理、反光或暗区较明显的图片；它们仍然是正常标签。
- `maskless_ng_view`：异常零件的某些视角没有可见 mask；这类图片保留为单独参考，不作为有 mask 的真实异常使用。

当前分类训练样本统计（fold1/train）：18 类、3755 个零件组、18775 个视角；其中 2695 个正常零件组、1060 个异常零件组。按视角标签统计：2993 个正常视角、15782 个可见异常视角。原 E1 的伪异常不放入本目录。
