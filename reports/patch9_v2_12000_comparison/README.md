## 比较范围与口径

三组分割主指标使用同一Dev的1775张异常图、18类，阈值均为0.5、GT为448×448。已核对逐图文件：异常图路径集合完全一致，逐图GT像素面积全部一致。Macro Dice/IoU为先求类别内逐图均值、再对18类平均；Precision/Recall为异常图逐图均值。均为分割模型独立评测，未经过分类器筛选。

本轮同时评测1825张正常图，总计3600张。Baseline现有单模型评测只含1775张异常图，正常图结果不可由此前两阶段结果代替，表中标为未评测。差值使用原始0–1指标相减，例如0.0253等于2.53个百分点。

## 训练和推理条件

| 项目 | Baseline | Patch9-v2 |
| --- | --- | --- |
| 模型 | 冻结Qwen3-VL-2B，训练decoder | 冻结Qwen3-VL-2B，训练decoder |
| optimizer步数 | 12000 | 12000 |
| 每步输入 | 8张异常整图 | 2异常整图+2含缺陷patch+1异常图空patch+1正常patch+2正常整图 |
| 非空监督曝光 | 96000次 | 48000次 |
| 推理 | 全图一次前向 | 全图一次前向，或全图+9个patch共10次前向 |
| 九宫格融合 | — | 原图裁剪、回投，mean_w0.5 |

本轮与baseline同时改变采样和空目标监督，且非空监督曝光减半，不能把跨模型差异单独归因于九宫格。10次前向也不等价于已经实测的10倍总耗时。

## 结论

- 同一Patch9-v2模型使用融合后，Macro Dice从0.7292升至0.7545（+2.53个百分点），Macro IoU增加3.39个百分点，正常图非空预测率从42.63%降至32.77%。
- 对比12000步baseline，融合Macro Dice低2.01个百分点，Macro IoU低1.80个百分点；Precision提高2.06个百分点，Recall下降4.56个百分点。因此本轮尚未在整体分割质量上超过baseline。
- tiny Dice从baseline的0.3184提高到0.3832，tiny Recall从0.5329提高到0.5996；small和large Dice仍低于baseline。局部放大对极小缺陷有改善，但不能外推为所有缺陷均改善。
- Dev最佳step11000的融合Macro Dice为0.7565，仍低于baseline的0.7746。上方主表统一使用step12000，避免把最佳节点与最终节点混用。
