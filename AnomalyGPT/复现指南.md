# AnomalyGPT 复现指南

> 面向：想在本机/实验室复现 AnomalyGPT（AAAI 2024, arXiv 2308.15366）的训练与评测。
> 依据：`AnomalyGPT/code/` 实际代码（clone 于 2026-10-22，commit f21c51b）+ 论文 + 官方 README。
> 文中标注「估算」的数字是我按代码结构与常见硬件推算的，不是官方数据。

---

## 0. 一页结论

| 项目 | 最低配置 | 推荐配置 | 说明 |
|---|---|---|---|
| **GPU** | **2 × 24GB**（RTX 3090） | 2 × 48GB（A6000 / L40） | 官方就是 2×3090 训的；单卡也能跑但要改配置 |
| **显存/卡** | ≈20–22 GB | 更宽裕 | Vicuna-7B(fp16) 约 13GB + ImageBind-Huge 约 2.4GB + 激活 |
| **CPU 内存** | 64 GB | 128 GB | DeepSpeed ZeRO-2 要把优化器状态 offload 到 CPU |
| **磁盘** | 60 GB | 100 GB | 权重 ≈25GB + MVTec ≈5GB + PandaGPT 数据 ≈20GB |
| **训练时长** | — | **6–10 小时**（估算） | 50 epoch × 约 227 步/epoch，2×3090 |
| **数据** | MVTec-AD（必须） | + VisA | 训练只需**正常图**，异常图是在线合成的 |
| **周期** | 只推理：半天 | 完整训练+评测：**3–5 天** | 含环境、权重、调试 |

**一句话**：这不是"下载即跑"的仓库——它依赖 **Vicuna v0**，而 Vicuna 需要你**自己从 LLaMA 权重合并**。这是整个流程里最耗时、最容易卡住的一步。

## 1. 先确定你要复现到哪一步

三条路径，工作量差很多，先选：

| 路径 | 做什么 | 时间 | 需要什么 |
|---|---|---|---|
| **A. 只推理** | 用官方权重跑 `code/test_mvtec.py` | **半天** | 2×24GB、三件套权重、MVTec |
| **B. 复现训练 + 评测** | 从 PandaGPT 初始化，训 50 epoch，复现论文数字 | **3–5 天** | 同上 + PandaGPT 图文数据 |
| **C. 完全从零** | 连 Vicuna 也自己合并 | B + 1–2 天 | 还需 LLaMA 权重（要申请） |

**建议先走 A**：先把推理跑通，确认环境、权重、数据都没问题，再去碰训练。训练出问题时，你至少知道不是环境的问题。

## 2. 硬件准备

### 2.1 GPU

| 项 | 值 | 依据 |
|---|---|---|
| 卡数 | **2 张** | `scripts/train_mvtec.sh` 写死 `--include localhost:0,1` |
| 单卡显存 | **24GB** | 官方声明 "2 × RTX 3090" |
| 架构 | Ampere 及以上 | 需要 fp16 + bf16 支持 |

**显存账（估算）**：

```
Vicuna-7B (fp16)              ≈ 13.5 GB
ImageBind-Huge (fp16)         ≈  2.4 GB   （4.5GB 的 fp32 权重转半精度）
LoRA / prompt / decoder       ≈  0.5 GB
激活（batch 1，seq 1024）      ≈  3–5 GB
────────────────────────────────────────
合计                          ≈ 20–22 GB / 卡
```

**单卡能不能跑？** 能，但要改两处：
1. `scripts/train_mvtec.sh` 里 `--include localhost:0,1` → `localhost:0`；
2. `code/dsconfig/openllama_peft_stage_1.json` 里 `"stage": 2` → `"stage": 3`（ZeRO-3 会切分参数，代价是更慢）。

单卡 24GB 跑 ZeRO-3 + offload，速度大约是双卡的 50–60%（估算）。

### 2.2 CPU 与磁盘

- **内存 ≥64GB**：ZeRO-2 的 `offload_optimizer: cpu` 会把优化器状态放内存。
- **磁盘 ≥60GB**：权重 ~25GB、MVTec ~5GB、PandaGPT 图文数据 ~20GB（解压后）。

## 3. 软件环境

### 3.1 版本要求

```text
Python        3.9 ~ 3.10
CUDA          11.7（torch 1.13.1+cu117 对应）
PyTorch       1.13.1
DeepSpeed     0.9.2          ← 版本很关键，新版本 API 变了
transformers  4.29.1
peft          0.3.0
timm          0.6.7
numpy         1.24.3         ← 不要升到 2.x，会与旧 torch 冲突
```

完整依赖见 `AnomalyGPT/code/requirements.txt`。

### 3.2 安装顺序（重要）

```bash
conda create -n anomalygpt python=3.9 -y
conda activate anomalygpt

# 1) 先装 torch（指定 CUDA 版本）
pip install torch==1.13.1+cu117 torchvision==0.14.1+cu117 torchaudio==0.13.1 \
    --extra-index-url https://download.pytorch.org/whl/cu117

# 2) 再装 deepspeed（必须匹配 torch 版本编译）
pip install deepspeed==0.9.2

# 3) 其余依赖
pip install -r requirements.txt
```

**顺序不能乱**：先装 torch 再装 deepspeed，否则 deepspeed 会按错误的 torch 版本编译，import 时报 `undefined symbol`。

### 3.3 常见环境坑

| 现象 | 原因 | 解决 |
|---|---|---|
| `undefined symbol: ...c10...` | deepspeed 编译时用的 torch 版本不一致 | 卸掉 deepspeed 重装 |
| `cannot import name 'LlamaTokenizer'` | transformers 版本过低 | 固定 4.29.1 |
| `numpy` 报 ABI 错误 | 装到了 numpy 2.x | `pip install "numpy<2"` |
| `deepspeed` 找不到 `DS_BUILD_OPS` | 未编译自定义算子 | `DS_BUILD_OPS=1 pip install deepspeed==0.9.2`（可选，慢一点也能跑） |

## 4. 权重准备（最耗时的一步）

### 4.1 三件套

| 权重 | 大小 | 来源 | 放到 |
|---|---|---|---|
| **ImageBind-Huge** | 4.5 GB | `https://dl.fbaipublicfiles.com/imagebind/imagebind_huge.pth` | `code/pretrained_ckpt/imagebind_ckpt/` |
| **Vicuna-7B v0** | ~13 GB | **需要自己合并**（见 4.2） | `code/pretrained_ckpt/vicuna_ckpt/7b_v0/` |
| **PandaGPT delta** | ~0.2 GB | `openllmplayground/pandagpt_7b_max_len_1024`（HF） | `code/pretrained_ckpt/pandagpt_ckpt/7b/pytorch_model.pt` |
| **AnomalyGPT 权重**（可选） | ~0.2 GB | `FantasticGNU/AnomalyGPT` 的 `train_mvtec/pytorch_model.pt` | `code/ckpt/` |

> **状态（2026-10-22 已下载并校验）**
>
> | 权重 | 实际大小 | 校验 |
> |---|---|---|
> | ImageBind-Huge | 4.80 GB | 可 `torch.load`，键名与 `imagebind_huge()` 对齐 |
> | Vicuna-7B（社区合并镜像） | 13.48 GB | 两个 shard 均为合法存档，323 个权重键 |
> | PandaGPT delta | 76 MB | ✅ |
> | AnomalyGPT ×3 | 215 MB / 个 | 21 个键与 `LinearLayer`+`PromptLearner` 完全一致 |
>
> 明细见 `code/pretrained_ckpt/SOURCES.md`。
>
> ⚠️ **Vicuna 说明**：官方 `lmsys/vicuna-7b-v0` 已 401 不可访问，本次用的是社区合并镜像
> `Ejafa/vicuna_7B_vanilla`。结构正确但**无法逐位验证是否等于官方 v0**。严格复现请改用
> 「官方 delta + LLaMA」自行合并后替换 `vicuna_ckpt/7b_v0/`，代码无需改动。

### 4.2 Vicuna-7B v0 怎么来（关键步骤）

AnomalyGPT 用的是 **Vicuna version 0**，而 Vicuna 本身是 **LLaMA + delta 权重**合成出来的。流程：

```
① 申请 LLaMA 权重（Meta 表单，通常几小时到几天）
   https://docs.google.com/forms/d/e/1FAIpQLSfqNECQnMkycAp2jP4Z9TFX0cGR4uf7b_fBxjY_OjhJILlKGA/viewform

② 转成 HuggingFace 格式（官方提供转换脚本 convert_llama_weights_to_hf.py）
   → 得到 config.json / pytorch_model-0000x-of-00002.bin / tokenizer.model ...

③ 下载 Vicuna delta 权重
   https://huggingface.co/lmsys/vicuna-7b-delta-v0

④ 用 fastchat 的 apply_delta 合并
   python -m fastchat.model.apply_delta \
       --base-model-path /path/to/llama-7b-hf \
       --target-model-path /path/to/vicuna-7b-v0 \
       --delta-path /path/to/vicuna-7b-delta-v0

⑤ 把合并结果放到 code/pretrained_ckpt/vicuna_ckpt/7b_v0/
```

**如果拿不到 LLaMA 权重**：Vicuna v0 的公开副本在 HF 上有若干镜像（`lmsys/vicuna-7b-v0`、社区备份），但**许可与可用性由你自行确认**。这一步是整个复现里唯一"可能需要等"的环节。

## 5. 数据准备

### 5.1 需要三份数据

| 数据 | 用途 | 大小 | 来源 |
|---|---|---|---|
| **MVTec-AD** | 训练 + 评测 | ≈5 GB | mvtec.com 官网（需填表） |
| **PandaGPT 图文指令数据** | 交替训练（防遗忘） | ≈20 GB | `openllmplayground/pandagpt_visual_instruction_dataset` |
| **VisA**（可选） | 跨域评测 | ≈2 GB | amazon-science/spot-diff |

### 5.2 MVTec 目录结构（必须严格一致）

```
data/mvtec_anomaly_detection/
├── bottle/
│   ├── train/good/xxx.png
│   ├── test/good/xxx.png
│   ├── test/broken_large/xxx.png
│   └── ground_truth/broken_large/xxx_mask.png
├── capsule/
└── ...（共 15 类）
```

**关键点**：训练只需要 `train/good/` 里的**正常图**。异常图是**在线合成**的——
`code/datasets/mvtec.py` 用 `patch_ex`（self_sup_tasks 里的 Cut-paste）在训练时实时造异常，
每个类有专门的参数（`WIDTH_BOUNDS_PCT`、`NUM_PATCHES`、`INTENSITY_LOGISTIC_PARAMS`）。**你不需要预先造异常图。**

### 5.3 PandaGPT 数据

```
data/
├── pandagpt4_visual_instruction_data.json
└── images/...
```

这份数据是 16 万条图文指令，训练时与 MVTec 数据**交替采样**，防止模型忘掉对话能力。

### 5.4 磁盘占用

```
MVTec          5 GB
PandaGPT 数据  20 GB
权重           25 GB
coco/其他       —
──────────────────
合计          ~50 GB（建议留 100GB）
```

## 6. 训练

### 6.1 命令

```bash
cd code
bash scripts/train_mvtec.sh
```

脚本内容（`scripts/train_mvtec.sh`）：

```bash
deepspeed --include localhost:0,1 --master_port 28400 train_mvtec.py \
    --model openllama_peft \
    --stage 1 \
    --imagebind_ckpt_path ../pretrained_ckpt/imagebind_ckpt/imagebind_huge.pth \
    --vicuna_ckpt_path ../pretrained_ckpt/vicuna_ckpt/7b_v0/ \
    --delta_ckpt_path ../pretrained_ckpt/pandagpt_ckpt/7b/pytorch_model.pt \
    --max_tgt_len 1024 \
    --data_path ../data/pandagpt4_visual_instruction_data.json \
    --image_root_path ../data/images/ \
    --save_path ./ckpt/train_mvtec/ \
    --log_path ./ckpt/train_mvtec/log_rest/
```

### 6.2 超参（来自 README + config）

| 超参 | 值 | 出处 |
|---|---|---|
| epoch | 50 | `config/openllama_peft.yaml` |
| batch size（总） | 16 | `dsconfig/*.json` 的 `train_batch_size` |
| micro batch / 卡 | **1** | 同上 |
| 梯度累积 | 8 | 同上，2 卡 × 1 × 8 = 16 |
| learning rate | 1e-3 | 论文 / README |
| 最大长度 | 1024 | 命令参数 |
| ZeRO stage | 2 + CPU offload | dsconfig |
| 精度 | fp16 | dsconfig |
| 可训练参数 | 只有 decoder + prompt learner | 论文 |

### 6.3 时间与显存（估算）

```
MVTec 训练样本 ≈ 3600 张正常图（每 epoch）
batch 16 → 约 225 步/epoch
50 epoch → 约 11,000 步
每步 ≈ 1.5–3 s（2×3090，含前后向）  →  5–9 小时
```

**注意**：虽然只训 decoder 和 prompt learner，但**前向要过完整的 7B Vicuna**，
而且 ImageBind-Huge 也在前向图里。所以它比"只训 LoRA"的那种微调慢得多。

### 6.4 训练产出

```
code/ckpt/train_mvtec/
├── pytorch_model.pt      ← 最终权重（只含可训练部分）
└── log_rest/
```

## 7. 评测

```bash
cd code
python test_mvtec.py --few_shot True --k_shot 1 --round 3
```

| 参数 | 含义 | 默认 |
|---|---|---|
| `--few_shot` | 是否走 few-shot（memory bank）路径 | True |
| `--k_shot` | 每类用几张正常图建库 | 1 |
| `--round` | 重复次数（取平均） | 3 |

**脚本内部**（`code/test_mvtec.py`）：
- 内置 15 个类的自然语言描述（`describles` 字典），**不需要你额外写 prompt**；
- 输出 image AUC / pixel AUC / accuracy 三个指标；
- 需要把训练好的权重放到脚本指定的 `ckpt` 路径。

**期望数字**（论文，跨域 1-shot 训 VisA/测 MVTec）：image AUC 94.1、pixel AUC 95.3、accuracy 86.1%。
同域（训 MVTec/测 MVTec）：97.4 / 93.1 / 93.3%。

## 10. 风险清单（按踩坑概率排序）

| # | 风险 | 概率 | 应对 |
|---|---|---|---|
| 1 | **拿不到 LLaMA 权重** | 高 | 用社区 Vicuna v0 镜像；或改用 v1.5（需改 tokenizer 与位置编码，不推荐） |
| 2 | DeepSpeed 0.9.2 装不上 / 编译失败 | 中高 | 严格按"先 torch 后 deepspeed"顺序；必要时用 Docker |
| 3 | 显存 OOM（单卡或 batch 设置不对） | 中 | 改 ZeRO-3 + offload；确认 micro batch = 1 |
| 4 | 数据路径不对（相对路径 `../data`） | 中 | 严格按 README 的目录树摆 |
| 5 | PandaGPT 数据太大下载慢 | 中 | 它只用于交替训练，可先用小样本跑通流程 |
| 6 | fp16 训练不稳定 / loss 变 NaN | 中 | 降 lr、加 warmup、检查 grad clipping（已在 dsconfig 设为 1.0） |
| 7 | 复现数字对不上论文 | 中 | 先确认是"同域"还是"跨域"设置（见第 7 节）；再看随机种子 |

## 11. 最小验证路径（建议先做这个）

如果你只想确认"这套东西能跑"，不要一上来就训练：

```text
1. 环境装好，import 全部通过                        （2 h）
2. 合并 Vicuna，下载 ImageBind / PandaGPT delta      （3 h + 等 LLaMA）
3. 直接用官方 AnomalyGPT 权重跑 test_mvtec.py        （1 h）
4. 确认指标接近论文，再开始自己训                     —
```

**注意**：即使只做推理，**Vicuna 也绕不开**——它是模型的一部分，不是可选的。
所以正确的顺序是：**先把 Vicuna 搞定**，其余下载可以并行。

## 12. 一句话总结

> AnomalyGPT 的复现难点不在代码（代码结构清晰、依赖少），而在**三件外部资产**：
> **Vicuna v0（要自己合并）**、**ImageBind-Huge（4.5GB）**、**PandaGPT 图文数据（20GB）**。
> 硬件门槛是 **2×24GB**，训练 6–10 小时，整体 3–5 个工作日。
